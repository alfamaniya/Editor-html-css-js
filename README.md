<h1>Editor HTML / CSS / JS</h1>
<p>A browser-based playground for writing HTML, CSS, and JavaScript, with a live preview and a compact file-management workflow.</p>

<h2>Features</h2>
<ul>
<li><strong>HTML, CSS, and JavaScript editors</strong> with syntax highlighting and line numbers.</li>
<li><strong>Live preview</strong> to see the result of your code.</li>
<li><strong>Project file explorer</strong> to add, rename, switch between, and remove files.</li>
<li><strong>Library manager</strong> for adding optional CSS and JavaScript libraries.</li>
<li><strong>Search</strong> through editor content, with next/previous matches.</li>
<li><strong>Editing helpers</strong> including undo/redo, font-size controls, and keyboard shortcuts.</li>
<li><strong>Save and download</strong> options for your code and project files.</li>
<li>Responsive, dark-themed interface.</li>
</ul>

<h2>Project files</h2>
<ul>
<li><code>index.html</code> — page structure and editor interface.</li>
<li><code>style.css</code> — styles for the editor interface, separated from the HTML.</li>
<li><code>script.js</code> — JavaScript application logic, separated from the HTML.</li>
<li><code>README.md</code> — project documentation in English and Persian.</li>
</ul>

<h2>Run the project</h2>
<ol>
<li>Download or clone this repository.</li>
<li>Keep <code>index.html</code>, <code>style.css</code>, and <code>script.js</code> in the same directory.</li>
<li>Open <code>index.html</code> in a modern browser.</li>
</ol>
<p>No build step is required for the basic editor page.</p>

<h2>Keyboard shortcuts</h2>
<ul>
<li><code>Ctrl/Cmd + S</code> — save the current project.</li>
<li><code>Ctrl/Cmd + Shift + S</code> — open the download dialog.</li>
<li><code>Ctrl/Cmd + F</code> — focus the editor search.</li>
<li><code>Ctrl/Cmd + Z</code> — undo.</li>
<li><code>Ctrl/Cmd + Y</code> or <code>Ctrl/Cmd + Shift + Z</code> — redo.</li>
</ul>

<h2>Notes</h2>
<ul>
<li>The CSS is loaded from the local <code>style.css</code> file. Keep it alongside <code>index.html</code> so the interface can be styled correctly.</li>
<li>The editor's JavaScript logic is loaded from the local <code>script.js</code> file.</li>
<li>Persian comments inside the source code are intentionally preserved.</li>
</ul>

<h1 dir="rtl">ویرایشگر HTML / CSS / JS</h1>
<p dir="rtl">یک محیط کدنویسی در مرورگر برای نوشتن HTML، CSS و JavaScript همراه با پیش‌نمایش زنده و ابزارهای ساده مدیریت فایل.</p>

<h2 dir="rtl">امکانات</h2>
<ul dir="rtl">
<li><strong>ویرایشگرهای HTML، CSS و JavaScript</strong> همراه با رنگ‌بندی دستورات و شماره خطوط.</li>
<li><strong>پیش‌نمایش زنده</strong> برای مشاهده نتیجه کدها.</li>
<li><strong>مدیریت فایل‌های پروژه</strong> برای افزودن، تغییر نام، انتخاب و حذف فایل‌ها.</li>
<li><strong>مدیریت کتابخانه‌ها</strong> برای افزودن کتابخانه‌های اختیاری CSS و JavaScript.</li>
<li><strong>جست‌وجو</strong> در محتوای ویرایشگر و رفتن به نتیجه قبلی یا بعدی.</li>
<li><strong>ابزارهای ویرایش</strong> شامل واگردانی و انجام دوباره، تنظیم اندازه قلم و میانبرهای صفحه‌کلید.</li>
<li><strong>ذخیره و دانلود</strong> کدها و فایل‌های پروژه.</li>
<li>رابط کاربری تیره و واکنش‌گرا.</li>
</ul>

<h2 dir="rtl">فایل‌های پروژه</h2>
<ul dir="rtl">
<li><code>index.html</code> — ساختار صفحه و رابط ویرایشگر.</li>
<li><code>style.css</code> — ظاهر و استایل‌های رابط ویرایشگر که از HTML جدا شده‌اند.</li>
<li><code>script.js</code> — منطق برنامه با JavaScript که از HTML جدا شده است.</li>
<li><code>README.md</code> — مستندات پروژه به دو زبان فارسی و انگلیسی.</li>
</ul>

<h2 dir="rtl">اجرای پروژه</h2>
<ol dir="rtl">
<li>مخزن را دانلود یا کلون کنید.</li>
<li>فایل‌های <code>index.html</code>، <code>style.css</code> و <code>script.js</code> را در یک پوشه نگه دارید.</li>
<li>فایل <code>index.html</code> را با یک مرورگر به‌روز باز کنید.</li>
</ol>
<p dir="rtl">برای اجرای پایه صفحه ویرایشگر، نیازی به مرحله ساخت (Build) نیست.</p>

<h2 dir="rtl">میانبرهای صفحه‌کلید</h2>
<ul dir="rtl">
<li><code>Ctrl/Cmd + S</code> — ذخیره پروژه فعلی.</li>
<li><code>Ctrl/Cmd + Shift + S</code> — باز کردن پنجره دانلود.</li>
<li><code>Ctrl/Cmd + F</code> — رفتن به کادر جست‌وجوی ویرایشگر.</li>
<li><code>Ctrl/Cmd + Z</code> — واگردانی آخرین تغییر.</li>
<li><code>Ctrl/Cmd + Y</code> یا <code>Ctrl/Cmd + Shift + Z</code> — انجام دوباره تغییر.</li>
</ul>

<h2 dir="rtl">نکته‌ها</h2>
<ul dir="rtl">
<li>استایل‌ها از فایل محلی <code>style.css</code> بارگذاری می‌شوند. برای نمایش درست ظاهر برنامه، این فایل باید کنار <code>index.html</code> باشد.</li>
<li>منطق JavaScript ویرایشگر از فایل محلی <code>script.js</code> بارگذاری می‌شود.</li>
<li>کامنت‌های فارسی داخل کد عمداً حفظ شده‌اند.</li>
</ul>
