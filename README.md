# ویرایشگر HTML / CSS / JavaScript

یک ویرایشگر کدنویسی سمت مرورگر برای ساخت و آزمایش صفحه‌های وب. کدهای HTML، CSS و JavaScript را در ویرایشگرهای جداگانه بنویسید و نتیجه را در پیش‌نمایش زنده ببینید. برنامه به نصب وابستگی‌های npm نیاز ندارد.

## اجرا

### اجرای مستقیم

فایل `index.html` را در یک مرورگر به‌روز باز کنید. برای توسعهٔ محلی می‌توانید از سرور سادهٔ Python نیز استفاده کنید:

```powershell
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

### نسخهٔ مستقل

`index-test-etitor.html` یک خروجی تولیدشده و یک‌فایلی از ویرایشگر است و برای اجرا به فایل‌های محلی دیگر پروژه وابستگی ندارد. منابع اصلی توسعه، `index.html`، فایل‌های CSS و JavaScript هستند؛ تغییرات را در آن‌ها انجام دهید، نه در خروجی تولیدشده.

برای ساخت و بررسی نسخهٔ مستقل با Node.js 20 یا جدیدتر:

```powershell
node scripts/build-test-editor.mjs
node scripts/check-standalone-editor.mjs
```

ساخت خروجی در GitHub Actions نیز از صفحهٔ **Actions** و با اجرای دستی workflow مربوط به ساخت نسخهٔ مستقل امکان‌پذیر است و به تأیید صریح نیاز دارد.

## قابلیت‌ها

- ویرایش جداگانهٔ HTML، CSS و JavaScript همراه با برجسته‌سازی نحوی، شمارهٔ خطوط و پیش‌نمایش زنده.
- منوهای **File، Edit، View و Help** برای دسترسی به مدیریت پروژه، ویرایش، نمایش و راهنما.
- مدیریت فایل‌های پروژه، ایجاد و تغییرنام فایل، جست‌وجو و فیلتر فایل‌ها.
- ذخیرهٔ خودکار پروژه در حافظهٔ محلی مرورگر و امکان ذخیرهٔ دستی؛ این ذخیره‌سازی ابری یا همگام‌سازی میان دستگاه‌ها نیست.
- جست‌وجو در کد، بازگشت و انجام دوباره، درج سریع قطعه‌کد و پیشنهادهای HTML/CSS/JavaScript.
- پالت انتخاب رنگ در مقادیر رنگی CSS، ویژگی‌های رنگی درون‌خطی HTML و رشته‌های رنگی JavaScript؛ امکان انتخاب رنگ، ویرایش مقدار و اعمال آن در کد.
- پیش‌نمایش زنده، بازرس عناصر پیش‌نمایش، تنظیم چیدمان و ظاهر، درخت کلمات و مدیریت کتابخانه‌ها.
- دانلود خروجی HTML یا فایل‌های پروژه و تهیه یا بازیابی نسخهٔ پشتیبان از تنظیمات و داده‌های پشتیبانی‌شده.
- رابط واکنش‌گرا برای نمایشگرهای کوچک و بزرگ.

پیش‌نمایش کد کاربر در یک `iframe` با `sandbox` اجرا می‌شود. برخی کتابخانه‌ها از CDN بارگیری می‌شوند و استفاده از آن‌ها به اتصال اینترنت نیاز دارد.

## کلیدهای میانبر

| میانبر | عملکرد |
|---|---|
| `Ctrl+S` یا `⌘+S` | ذخیرهٔ پروژه در مرورگر |
| `Ctrl+Shift+S` یا `⌘+Shift+S` | باز کردن گزینه‌های دانلود |
| `Ctrl+F` یا `⌘+F` | جست‌وجو در کد |
| `Ctrl+Z` یا `⌘+Z` | بازگشت |
| `Ctrl+Y` یا `⌘+Y`؛ همچنین `Ctrl+Shift+Z` یا `⌘+Shift+Z` | انجام دوباره |

## ساختار پروژه

```text
Editor-html-css-js/
├── .github/workflows/       # بررسی خودکار و ساخت دستی نسخهٔ مستقل
├── docs/
│   └── suggestions/         # پیشنهادها و یادداشت‌های توسعه
├── scripts/                 # ساخت و بررسی پروژه
├── src/features/
│   ├── backup-restore/      # پشتیبان‌گیری و بازیابی
│   ├── live-preview/        # ابزارهای پیش‌نمایش زنده
│   ├── quick-insert/        # نوار درج سریع
│   ├── settings/            # تنظیمات
│   ├── suggestions/         # پیشنهادها و مدیریت آن‌ها
│   ├── word-tree/           # درخت کلمات
│   └── workspace/
│       ├── file-manager/    # نمایش فایل‌ها و پنل کشویی
│       ├── search/          # هدر، جست‌وجو و منوهای محیط کار
│       └── toolbar/         # سایدبار ابزارها
├── tools/
│   └── build-single-file.js # ورودی قدیمی سازندهٔ نسخهٔ مستقل
├── index.html               # صفحهٔ اصلی و ساختار رابط
├── index-test-etitor.html   # خروجی مستقل تولیدشده
├── script.js                # منطق اصلی ادیتور، از جمله پالت رنگ
└── style.css                # استایل اصلی رابط و ادیتور
```

`src/features/editor/color-picker/` در حال حاضر فقط `.gitkeep` دارد؛ منطق فعلی پالت رنگ در `script.js` قرار دارد. بعضی پوشه‌های `src/app/` و `src/shared/` نیز جایگاه توسعهٔ آینده‌اند و فایل `.gitkeep` به‌تنهایی به معنی پیاده‌سازی قابلیت نیست. منطق برنامه هنوز کاملاً از فایل‌های اصلی ریشه به ماژول‌های `src/features/` منتقل نشده است.

## بررسی‌ها و آزمون‌ها

برای اجرای بررسی‌ها، Node.js 20 یا جدیدتر نصب باشد. فرمان‌ها را از پوشهٔ اصلی مخزن اجرا کنید:

```powershell
node scripts/check-index-integrity.mjs
node scripts/check-editor-code-processing.mjs
node scripts/check-settings-dialog-keyboard.mjs
node scripts/check-backup-restore.mjs
node scripts/check-standalone-editor.mjs
```

برای اطمینان از صحت نحو فایل اصلی JavaScript:

```powershell
node --check script.js
```

workflowهای موجود در `.github/workflows/` برخی از این بررسی‌ها را هنگام تغییر فایل‌های مرتبط در شاخهٔ `main` یا pull request اجرا می‌کنند.
