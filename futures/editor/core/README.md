# CodeMirror 6 Core

This directory is the local runtime location for the CodeMirror 6 browser bundle.

- `codemirror.js` is generated by `npm run build:codemirror`.
- Source imports and build configuration live in `scripts/codemirror-entry.js` and `scripts/build-codemirror.mjs`.
- Do not edit the generated bundle manually.
- The bundle is intended to be loaded locally; no CDN or runtime network request is required.

After cloning the repository, run `npm install`, then `npm run build:codemirror`.
