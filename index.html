HTML / CSS / JAVASCRIPT EDITOR

Editor User Guide

Learn the main controls, write code, preview changes, manage libraries, and export your project.

1. Understand the workspace

  • HTML, CSS, JS: switch between the three code editors.
  • Files: choose a file or use + to create another HTML, CSS, or JavaScript file.
  • Preview: the right-hand panel shows the rendered page. Changes are refreshed automatically after a short delay.
  • Libraries: browse supported browser libraries, add code, then enable or disable each saved library.
  • Help: this guide stays inside the editor; reopen it whenever you need instructions.

2. A simple first project

  1. Open HTML and write the page structure and visible elements.
  2. Open CSS and style those elements. For example, use body { font-family: sans-serif; }.
  3. Open JS to add interactions such as button clicks.
  4. Look at the preview. If something is wrong, inspect the code and make a small change at a time.

Tip: HTML defines the content, CSS controls the appearance, and JavaScript adds behavior.

3. Editing and autocomplete

  • Type an opening tag such as <di to see HTML tag suggestions.
  • Inside a tag, type a space to suggest attributes; suggestions depend on the element where supported.
  • Inside a CSS rule, start typing a property; after a colon, matching value suggestions may appear.
  • In JavaScript, try document. or console. to see known members and snippets.
  • Use the arrow keys to move through suggestions and Enter/Tab to accept when the suggestion list is open. Exact behavior can depend on the browser keyboard.

4. Save, undo, search, and reset

  • Save: stores the project in this browser's local storage. It is not a cloud backup.
  • Download: choose a project name and export either a complete HTML page or the project files.
  • Undo / Redo: use the arrow buttons or keyboard shortcuts below.
  • Search: find text in the code with the search field.
  • Reset: restores the starter project and replaces current code. Use it carefully; download a backup first.
  • Clear / Clear All: removes code from the current file or all project files.

5. Use the Libraries tab

  1. Search the catalog by library name or purpose, or filter to CSS/JavaScript.
  2. Select a catalog entry. The editor tries to fetch its browser-ready code from the listed CDN.
  3. If download fails, check your internet connection and the official library docs, then paste a browser-compatible build into the code box.
  4. Enter a name and choose CSS or JS if needed, then select Add to Libraries.
  5. In Saved Libraries, tick the checkbox to enable a dependency, or untick it to temporarily disable it. Use the trash button to remove it.

Important: many packages have dependencies, module-only builds, license conditions, or additional setup. A successful download does not guarantee that the library works without configuration. Avoid adding code from sources you do not trust.

6. What “offline” means

The editor interface and saved code can work locally after the files are available. CDN library downloads require internet access, and saved library code uses browser storage on this device. Clearing browser data may erase saved projects and libraries. Download important work regularly.

7. Export and open your project

  • Use Download, enter a project name, then choose a complete HTML file or the project bundle.
  • Keep related files together when using a multi-file export.
  • Open the exported HTML file in a modern browser to inspect it. Features that call external APIs or use CDN resources may still require internet access.
  • For larger projects, use version control and keep separate backups instead of relying only on local storage.

8. Troubleshooting

A library did not download

The CDN may block browser requests, be temporarily unavailable, or have changed the file path. Visit the official documentation, download a browser-ready build, and paste it manually. Some libraries cannot be used as a single script.

The preview is blank or outdated

Check for incomplete HTML, CSS syntax errors, JavaScript errors, or a missing dependency. Try a small change and wait for the preview refresh. Some browser security restrictions affect local files.

My saved code disappeared

Check whether you opened the editor in a different browser or private session. Browser storage is local to that browser profile and may be deleted when site data is cleared. Use Download for a backup.

A library was saved but does not work

Confirm that the correct build and version were added, required dependencies are enabled, and the official setup instructions were followed.

This guide describes the intended workflow. Browser, mobile keyboard, and assistive-technology behavior should still be tested on the device where you plan to use the editor.

۱. آشنایی با محیط ویرایشگر

  • HTML، CSS و JS: با این زبانه‌ها بین سه محیط ویرایش کد جابه‌جا شوید.
  • فهرست فایل‌ها: یک فایل را انتخاب کنید یا با دکمه + فایل HTML، CSS یا JavaScript جدید بسازید.
  • پیش‌نمایش: پنل سمت راست نتیجه اجرای صفحه را نشان می‌دهد. تغییرات پس از مکث کوتاهی به‌طور خودکار به‌روزرسانی می‌شوند.
  • کتابخانه‌ها: کتابخانه‌های قابل استفاده در مرورگر را پیدا کنید، کدشان را اضافه کنید و سپس هر کتابخانه ذخیره‌شده را فعال یا غیرفعال کنید.
  • راهنما: این راهنما داخل ویرایشگر قرار دارد و هر زمان لازم باشد می‌توانید دوباره آن را باز کنید.

۲. ساخت اولین پروژه

  1. زبانه HTML را باز کنید و ساختار صفحه و عناصر قابل مشاهده را بنویسید.
  2. به CSS بروید و ظاهر عناصر را تنظیم کنید؛ برای نمونه: body { font-family: sans-serif; }.
  3. در JS رفتارهایی مانند واکنش به کلیک دکمه‌ها را اضافه کنید.
  4. نتیجه را در پیش‌نمایش ببینید. اگر مشکلی وجود داشت، کد را بررسی کنید و هر بار یک تغییر کوچک انجام دهید.

نکته: HTML محتوای صفحه را مشخص می‌کند، CSS ظاهر آن را می‌سازد و JavaScript رفتار و تعامل را اضافه می‌کند.

۳. ویرایش کد و تکمیل خودکار

  • برای دیدن پیشنهاد تگ‌های HTML، بخشی از تگ مانند <di را تایپ کنید.
  • داخل تگ، با وارد کردن فاصله پیشنهاد ویژگی‌ها نمایش داده می‌شوند؛ در موارد پشتیبانی‌شده این پیشنهادها به نوع عنصر وابسته‌اند.
  • داخل یک قانون CSS نام ویژگی را شروع کنید؛ پس از دونقطه ممکن است مقادیر مرتبط پیشنهاد شوند.
  • در JavaScript عبارت‌هایی مانند document. یا console. را امتحان کنید تا اعضا و قطعه‌کدهای شناخته‌شده پیشنهاد شوند.
  • وقتی فهرست پیشنهادها باز است، با کلیدهای جهت‌نما حرکت کنید و با Enter یا Tab پیشنهاد را بپذیرید. رفتار دقیق ممکن است به مرورگر و صفحه‌کلید وابسته باشد.

۴. ذخیره، بازگردانی، جست‌وجو و پاک‌سازی

  • Save (ذخیره): پروژه را در حافظه محلی همین مرورگر نگه می‌دارد؛ نسخه پشتیبان ابری نیست.
  • Download (دانلود): نام پروژه را تعیین کنید و یک فایل HTML کامل یا مجموعه فایل‌های پروژه را دریافت کنید.
  • Undo / Redo: از دکمه‌های پیکان یا میانبرهای صفحه‌کلید زیر استفاده کنید.
  • Search (جست‌وجو): متن موردنظر را در کد پیدا کنید.
  • Reset (بازنشانی): پروژه نمونه را برمی‌گرداند و کد فعلی را جایگزین می‌کند. پیش از آن نسخه پشتیبان بگیرید.
  • Clear / Clear All: کد فایل فعلی یا تمام فایل‌های پروژه را پاک می‌کند.

۵. استفاده از زبانه کتابخانه‌ها

  1. نام یا کاربرد کتابخانه را جست‌وجو کنید یا فهرست را به CSS و JavaScript محدود کنید.
  2. یک مورد را انتخاب کنید. ویرایشگر تلاش می‌کند کد آماده مرورگر را از CDN دریافت کند.
  3. اگر دریافت انجام نشد، اتصال اینترنت و مستندات رسمی را بررسی کنید و در صورت نیاز نسخه مناسب مرورگر را دستی دانلود کرده و کد آن را در کادر قرار دهید.
  4. در صورت نیاز نام کتابخانه و نوع CSS یا JS را تنظیم کنید و روی Add to Libraries بزنید.
  5. در بخش کتابخانه‌های ذخیره‌شده، تیک کنار کتابخانه را برای فعال‌سازی روشن یا برای غیرفعال‌سازی موقت خاموش کنید. برای حذف، از دکمه سطل زباله استفاده کنید.

مهم: بعضی بسته‌ها به وابستگی‌های دیگر، فایل‌های جداگانه، نسخه مخصوص مرورگر یا تنظیمات اضافی نیاز دارند. دریافت موفق فایل تضمین نمی‌کند که کتابخانه بدون پیکربندی کار کند. کد را فقط از منابع قابل اعتماد دریافت کنید.

۶. منظور از کارکرد آفلاین چیست؟

پس از در دسترس بودن فایل‌های ویرایشگر، خود محیط و کدهای ذخیره‌شده می‌توانند به‌صورت محلی استفاده شوند. دریافت کتابخانه از CDN به اینترنت نیاز دارد و کد کتابخانه‌ها در حافظه مرورگر همین دستگاه ذخیره می‌شود. پاک‌کردن داده‌های مرورگر ممکن است پروژه‌ها و کتابخانه‌های ذخیره‌شده را حذف کند؛ بنابراین مرتباً از کارهای مهم دانلود پشتیبان بگیرید.

۷. دریافت خروجی و بازکردن پروژه

  • روی Download بزنید، نام پروژه را وارد کنید و فایل HTML کامل یا بسته فایل‌های پروژه را انتخاب کنید.
  • در خروجی چندفایلی، فایل‌های مرتبط را کنار هم نگه دارید.
  • فایل HTML خروجی را در مرورگر به‌روز باز کنید. قابلیت‌هایی که از API خارجی یا منابع CDN استفاده می‌کنند ممکن است همچنان به اینترنت نیاز داشته باشند.
  • برای پروژه‌های بزرگ‌تر از کنترل نسخه و نسخه‌های پشتیبان جداگانه استفاده کنید و فقط به حافظه محلی مرورگر متکی نباشید.

۸. رفع مشکلات رایج

کتابخانه دانلود نشد

ممکن است CDN درخواست مرورگر را مسدود کند، موقتاً در دسترس نباشد یا مسیر فایل تغییر کرده باشد. مستندات رسمی را باز کنید، نسخه آماده مرورگر را دریافت کنید و کد را دستی وارد کنید. همه کتابخانه‌ها به‌صورت یک اسکریپت منفرد قابل استفاده نیستند.

پیش‌نمایش خالی است یا به‌روز نمی‌شود

کامل‌بودن HTML، خطاهای نحوی CSS، خطاهای JavaScript و وابستگی‌های مفقود را بررسی کنید. تغییر کوچکی انجام دهید و برای به‌روزرسانی پیش‌نمایش کمی صبر کنید. برخی محدودیت‌های امنیتی مرورگر روی فایل‌های محلی اثر می‌گذارند.

کد ذخیره‌شده ناپدید شده است

بررسی کنید ویرایشگر را در مرورگر دیگری یا حالت خصوصی باز نکرده باشید. حافظه مرورگر به همان نمایه کاربری وابسته است و با پاک‌کردن داده‌های سایت ممکن است حذف شود. برای پشتیبان از Download استفاده کنید.

کتابخانه ذخیره شده ولی کار نمی‌کند

بررسی کنید نسخه و فایل مناسب را اضافه کرده‌اید، وابستگی‌های لازم فعال هستند و دستورالعمل راه‌اندازی رسمی رعایت شده است.

این راهنما روند مورد انتظار کار را توضیح می‌دهد. عملکرد مرورگر، صفحه‌کلید موبایل و فناوری‌های کمکی را روی دستگاهی که قصد استفاده از آن را دارید نیز آزمایش کنید.
