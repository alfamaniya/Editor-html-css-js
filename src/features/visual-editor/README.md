# ویرایشگر بصری

این پوشه محل نگهداری قابلیت ویرایش بصری المان‌های پروژه است.

## فایل‌ها
- \`visual-editor.html\`: پوستهٔ مستقل Visual Editor.
- \`visual-editor.css\`: استایل‌های رابط کاربری استودیو.
- \`visual-editor.js\`: منطق طراحی بصری، پالت اجزا، پیش‌نمایش و پنل ویژگی‌ها.
- \`visual-editor-session.js\`: ابزار تراکنشی عمومی برای ثبت، بازگردانی و پیش‌نمایش تغییرات DOM.
- \`visual-editor-remote.js\`: اتصال امن پیام‌رسانی برای ویرایش المانی که از پیش‌نمایش Editor اصلی انتخاب می‌شود.

## مسیر انتخاب و ویرایش از Editor اصلی
1. کاربر در هدر Editor اصلی، دکمهٔ «انتخاب برای ویرایش بصری» را فعال می‌کند.
2. لایهٔ انتخاب درون پیش‌نمایش اصلی فعال می‌شود و المان‌ها را هنگام حرکت نشانگر مشخص می‌کند.
3. با کلیک روی یک المان، مشخصات، HTML و مقادیر CSS محاسبه‌شدهٔ آن از طریق پیام بین iframeها به پوستهٔ یکپارچه فرستاده می‌شود.
4. پوسته Visual Editor را باز می‌کند و همان المان را در ناحیهٔ پیش‌نمایش و پنل ویژگی‌ها نمایش می‌دهد.
5. تغییر هر ویژگی بلافاصله روی همان DOM زنده در پیش‌نمایش اصلی اعمال می‌شود؛ بنابراین listenerها و رفتار اصلی المان حفظ می‌شوند.
6. «ثبت تغییرات در کد اصلی» استایل‌های تغییرکرده را در ویژگی \`style\` تگ متناظر HTML می‌نویسد و پیش‌نمایش را از کد ذخیره‌شده دوباره می‌سازد.
7. «انصراف و بازگشت» ویژگی \`style\` اولیه را روی همان DOM زنده برمی‌گرداند و هیچ تغییری در سورس ذخیره نمی‌کند.

## قرارداد پیام‌رسانی و ذخیره‌سازی
- پیش‌نمایش فقط درخواست انتخاب یا تغییر CSS را به والد مستقیم خود می‌فرستد.
- پوستهٔ یکپارچه پیام‌ها را بر اساس منبع iframe به مقصد درست هدایت می‌کند؛ پیام‌های Visual Editor مستقیماً به iframe Editor اصلی فرستاده نمی‌شوند مگر از مسیر پوسته.
- تغییرات زنده فقط برای فهرست مشخصی از ویژگی‌های CSS مجازند.
- ثبت نهایی فقط وقتی انجام می‌شود که تگ انتخاب‌شده در یکی از فایل‌های HTML پروژه با شناسه یا ترتیب تگ قابل تطبیق باشد. برای المان‌هایی که صرفاً هنگام اجرا با JavaScript ساخته شده‌اند، ثبت سورس خودکار انجام نمی‌شود و پیام خطا نمایش داده می‌شود؛ در این حالت کاربر می‌تواند تغییر زنده را لغو کند.
- تغییرات ثبت‌شده به‌صورت inline style ذخیره می‌شوند تا به selector خارجی وابسته نباشند و با بازسازی پیش‌نمایش باقی بمانند.

## آزمون
آزمون Chromium در \`scripts/check-combined-editor-browser.mjs\` مسیر انتخاب از Editor، بازشدن Visual Editor، اعمال زندهٔ اندازهٔ متن، ثبت در HTML و بازگردانی کامل با انصراف را بررسی می‌کند.
