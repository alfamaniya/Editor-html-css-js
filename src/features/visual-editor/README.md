# ویرایشگر بصری

این پوشه محل نگهداری قابلیت ویرایش بصری المان‌های پروژه است.

## فایل‌ها
- `visual-editor.html`: پوستهٔ کامل استودیوی بصری منتقل‌شده از فایل قدیمی ریشه.
- `visual-editor.css`: استایل‌های رابط کاربری استودیو.
- `visual-editor.js`: منطق فعلی استودیوی طراحی و کنترل‌های آن.
- `visual-editor-session.js`: کنترل‌کنندهٔ تراکنش ویرایش روی DOM واقعی؛ تغییرات را تا Update موقت نگه می‌دارد و با Cancel بازمی‌گرداند.

## قرارداد حالت ویرایش در Editor اصلی
حالت نهایی باید کل صفحهٔ پیش‌نمایش را در context واقعی آن نشان دهد و المان انتخاب‌شده را برجسته کند. اتصال باید روی DOM اصلی پیش‌نمایش انجام شود؛ cloneNode مناسب نیست، زیرا listenerهای JavaScript را منتقل نمی‌کند.

چرخهٔ تراکنش:
1. `VisualEditorSession.begin(element)` ثبت وضعیت اولیه و برجسته‌سازی المان.
2. `VisualEditorSession.previewStyle(property, value)` پیش‌نمایش استایل.
3. `VisualEditorSession.update()` تثبیت تغییرات و دریافت وضعیت قبل/بعد.
4. `VisualEditorSession.cancel()` بازگرداندن وضعیت اولیه.

## وضعیت انتقال
استودیوی مستقل قبلی با حفظ کد رابط و منطق آن به ساختار ماژولار منتقل شده است. اتصال کامل دکمهٔ ورود به حالت ویرایش بصری در Editor، انتخاب المان از preview، نمایش کل صفحه در محیط ویرایش و اتصال Update/Cancel به فایل‌های اصلی Editor، مرحلهٔ بعدی یکپارچه‌سازی است و در این انتقال ساختاری انجام نشده است.
